# 0AMV 全市场动量轮动策略 · 独立复核与优化项目

> 基线策略：`0AMV全市场动量轮动策略B-V2-P1完整档案.docx`（用户手抄 0AMV 信号 + 44 只手工 ETF 池）
> 本项目目标：**全市场自动筛选版** + 独立数据复核 + 优化实验矩阵

## 架构

| 文件 | 作用 |
|---|---|
| `build_universe.py` | 全市场行业/主题 ETF 宇宙构建（东财名单 → 分类剔除宽基/债券/货币/商品/跨境/策略风格）|
| `fetch_universe_v2.py` | 批量抓前复权日线（腾讯源，限流友好，断点续传）|
| `bt.py` | 回测引擎：七层漏斗忠实复刻，信号源可插拔 |
| `run_experiments.py` | 优化实验矩阵：OFAT 单因子 + 阈值网格，样本内/外分列 |
| `defense_overlay.py` | 防守腿危机熔断独立检验 |
| `probe*.py` | 数据源探测记录（留存备查）|

## 数据源结论（2026-10-12 实测）

| 源 | 状态 | 用途 |
|---|---|---|
| 腾讯 `web.ifzq.gtimg.cn` | 可用，**有限流**（约 600 请求/小时级），返回 501 | 主力：前复权日线（复权经拆分事件验证正确）|
| 东财 push2/push2his | **本网络不通**（连接重置）| 不可用 |
| 新浪（akshare）| 可用，含成交额，**不复权** | 指数长历史、成交额类研究 |
| baostock | 可用，ETF 数据**实际不复权** | 交叉验证（限价格形态，限无拆分标的）|
| 东财 fundcode_search.js | 可用 | 基金名单 |

复权纪律：银行/煤炭/红利类高分红 ETF 用不复权数据会系统性低估收益、污染 RS 排名——**必须用前复权**（腾讯源已验证）。

## 已知数据问题（重要）

1. **`0amv_day.csv` 日期轴损坏**：数值序列按工作日网格排列，法定节假日不跳空（2025 春节休市周天天有值），
   约 7% 日子缺失，仅 2026 年与交易日历完全对齐。→ 机械重发的信号与用户手抄台账（96 条）对不上
   （机械重放 57 买/58 卖 vs 台账 40 段）。**台账到位前，回测结果为暂定口径。**
2. **宇宙幸存者偏差**：名单为当前在册 ETF，2019 以来清盘者缺失。
3. 腾讯限流后 `fetch_universe_v2.py` 重跑即可断点续传。

## 使用

```powershell
python fetch_universe_v2.py      # 补全/增量宇宙数据
python update_daily.py           # 每日增量更新（收盘后）
python bt.py                     # 基线回测（输出 outputs/）
python bt.py --exec-price open --cost 0.0015   # 变体
python run_experiments.py        # 优化实验矩阵
python defense_overlay.py        # 防守腿熔断检验
```
