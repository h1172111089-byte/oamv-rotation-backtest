## 当前研究口径

- 机械买入：max(活跃市值单日涨幅、相邻两交易日涨幅之和)>4%；单日<-2.3%退出，卖出优先。
- 行业主题ETF按RS20排序，历史资格、趋势、相关去重和原有自动单/双仓约束不变。
- 研究基线为次日收盘，不是固定双仓。默认`python bt.py`仍运行历史台账；机械入口必须显式指定。
- 用户目标为净总收益优先，回撤容忍约30%，不是回撤可保证的上限。
- 当前AMV是用户重整理的2012年以来版本。旧`0amv_day_fixed.csv`和`repair_amv.py`只留作历史，
  不要将推断日期覆盖到干净源文件，也不要按台账反推日期再声称独立验证。

## 快速验证：不联网、不下载行情

在本目录打开终端：

```powershell
python -m pip install -r requirements.txt
python regression_checks.py
python check_research_health.py
```

回归检查应全部通过。健康度检查读取**已封存历史结果**，回撤超30%和估值假设存在时
返回退出码2并报警，这是预期风险提示，不是安装失败；无结果/格式错误返回1。
不能把这项检查解读为今日信号、实时监控或实盘已准备好。

## 需要行情时再运行

```powershell
python fetch_data.py
python fetch_universe_v2.py
python bt.py --signals csv --entry-window 12 --exit-rule drop
```

缺价默认严格报错，不自动冻结为买入价。`--valuation-policy previous-close`仅允许明确标记的
前收盘估值假设，不能用于缺价成交，也不能据此通过上线验收。
新抓数据可能因复权修订、覆盖区间和源更新改变结果，不能拿旧收益数字当安装验收目标。

完整固定实验入口`python study_automatic.py`还需要`data/kline/sh000001_sina_long.csv`；
先按[家里机指南](家里机配置指南.md)补长日历。研究为固定2019—2026-10-09对照，不是自动延伸到今天。
完整输出在`outputs/automatic_research/`，封存输入在父目录`10-数据/data/raw/automatic_research/`；
两者均不进本Git仓库。换机器不会自动获得同一份行情快照，只有输入哈希一致时才能要求精确复现。

## 当前障碍与后续

- 候选分类混入过短融ETF；分类尚未修正重测。不要把当前结果当纯股票池最终基线。
- 部分ETF有缺价、当前目录存在存续偏差；512890的2021-10-22停牌/折算原因仍待官方核实。
- 前复权价格不等于真实成交和现金分红账，尚缺实盘价差、容量、涨跌停及最小交易单位约束。
- 旧开盘建议与长期宽基成交统计有计算错误，已修订；历史报告保留而不覆盖。
- 日更脚本不是交易系统，也不是完整操作单生成器；盘中更新、复权增量拼接和人工录入仍需检查。
- 新指标研究暂停追加。先处理数据分类、公司行动和回归验证，再决定是否研究独立资金/成分股信息。

## 代码入口

`bt.py`为组合引擎；`accounting.py`为自融资会计；`study_automatic.py`为固定实验。
`run_window_exit.py`只做信号/宽基对照；`run_experiments.py`、`run_flow.py`、`run_topn.py`为历史实验入口，
不要因它们曾经“更优/被否决”就自动修改现行策略。
`package_research_results.py`封装既有结果摘要；`check_research_health.py`是本仓库独立的风险检查。
